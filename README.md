## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/ginga-no-fumigura/kajii-senso/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。

受け取った修正は、底本と照らして確かめてから取り込みます。
